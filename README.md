# 柔性绿氨全生命周期智能规划平台 V1.1（计算逻辑修正版）

## 一、文件组成

- `web.py`：Streamlit Web端，保留五个功能模块。
- `model1.py`：风光资源数据读取、风光装机互补寻优。
- `model2.py`：统一8760小时物理调度、设备规模优化及结果导出。
- `model3.py`：固定模块二设备规模，反向优化风光装机并重新校核。
- `economics.py`：吨氨单耗、LCOA/LCOH、NPV、IRR和动态回收期。
- `model4_carbon.py`：简化边界碳足迹及减排率预判。
- `requirements.txt`：运行依赖。
- `启动Web端.bat`：Windows启动脚本。

## 二、运行方式

### 1. 安装依赖

在Windows命令提示符或PowerShell中，进入本目录后运行：

```bash
python -m pip install -r requirements.txt
```

### 2. 启动Web端

双击 `启动Web端.bat`，或执行：

```bash
python -m streamlit run web.py
```

### 3. 上传资源数据

风资源和光资源Excel至少包含以下字段：

- `time`：逐小时日期时间；
- `electricity/KW`：逐小时资源出力或可归一化资源序列。

程序读取前8760小时。风电和光伏的前8760小时必须使用完全一致的时间戳。程序分别使用各自资源文件中 `electricity/KW` 列的最大值进行归一化。

### 4. Web端计算顺序

1. 输入风光装机边界、目标供电基准线和模块一约束，运行模块一。
2. 输入“最低年产绿氨目标”，设置最大允许下网电率和最大允许弃电率，运行模块二。
3. 固定模块二设备规模，运行模块三反向优化风光装机。
4. 运行模块四，计算单耗和财务评价。
5. 运行模块五，计算简化边界碳足迹及减排率预判。

目标年产绿氨量是最低产量约束。若风光资源和设备条件允许，调度结果的实际产量可以高于该目标。

## 三、修正后的核心计算口径

### 1. 模块一：风光资源缺额率与理论弃电率

模块一只用于风光资源初步匹配：

- 资源缺额率：全年逐时目标基准负荷与风光出力之间的正向缺额电量，除以全年基准负荷电量。
- 理论弃电率：全年逐时风光出力超过目标基准线的电量，除以全年风光发电量。

模块一的资源缺额率不是实际电网下网电率，不能替代模块二、三的运行指标。

### 2. 模块二、三：最大允许下网电率

统一采用：

`全年下网电率 = 全年电网购电量 / (全年制氢耗电量 + 全年制氨耗电量)`

储能充电量属于内部能量转移，不重复计入分母。当前模型不允许电网直接给储能充电，也不模拟向电网反送电。

本版本没有设置年度最大下网电量或最大瞬时下网功率输入项；下网电率是年度比例约束。

### 3. 弃电率

统一采用：

`全年弃电率 = 全年弃电量 / 全年风光发电量`

风光发电量按风电装机×风电归一化出力与光伏装机×光伏归一化出力逐时相加后汇总。

### 4. 电解槽和储氢约束

- 电解槽逐时耗电不超过额定功率。
- 当小时合成氨耗氢先由储氢库存和当小时制氢量共同满足。
- 储氢库存逐时更新，不允许为负，也不允许超过储氢罐容量。
- 当小时有风光余电时，允许电解槽额外制氢以补充储氢库存；额外制氢不使用网电。
- 若氢气供应不足，合成氨产量自动降低，不再通过突破电解槽额定功率的方式虚构补氢。

### 5. 储能约束

- 储能SOC逐时更新。
- 充电、放电分别计入充电效率和放电效率。
- SOC不得低于0或超过额定容量。
- 最大充放电功率按“储能容量×功率倍率”计算，Web默认0.5C。
- Web默认充电效率和放电效率均为95%，均可调整。
- 电网补电不用于储能充电。

### 6. 年度库存边界与电量平衡

模拟从电池和储氢罐各自50%初始库存开始，重复运行年度8760小时序列，逐步逼近周期运行状态，并输出期初、期末库存和迭代收敛状态。

系统边界年度电量平衡为：

`风光发电量 + 网购电量 = 制氢耗电 + 制氨耗电 + 弃电量 + 电池损耗 + 电池库存变化`

氢气物料平衡为：

`制氢量 - 合成氨耗氢量 = 储氢库存变化`

若年度库存迭代未收敛，结果页会显示提示，不能将其视为严格周期稳态方案。

### 7. 经济性口径

模块二优化目标与模块四LCOA统一采用：

`LCOA = (年化投资 + 年运维费 + 年网电费 + 年水费) / 全年绿氨产量`

LCOH按氢系统投资年化成本、分摊网电费及制水费除以全年产氢量计算。

现金流评价为简化税前模型，未计所得税、折旧税盾、残值、流动资金、设备更换和融资结构。

## 四、模型假设和使用边界

1. 采用非闰年8760小时序列；月度检修按365天自然年小时数处理。
2. 自动选择风光发电量最低的月份作为一个月检修期；检修月电解槽及合成氨装置停运，电池仍可充电。
3. 合成氨装置按0至额定产能柔性调节；当前未设置最小稳定负荷、爬坡、启停时间和启停成本。
4. 未计入压缩机、泵、空分、循环水、冷却、照明等辅助用电；如项目需要，应将其加入工艺负荷。
5. 未计入氢气泄漏、储罐压缩能耗、管道压降、电解槽部分负荷效率变化、设备衰减和电池寿命衰减。
6. 设备规模寻优使用SLSQP多初始点方法，调度模型存在分段函数；多初始点可降低局部解风险，但不能保证数学意义上的全局最优。
7. 若设备规模触及搜索上下限，应扩大设备边界并重新计算。
8. 模块三固定模块二设备规模。若模块三对风光装机修正幅度较大，建议将修正后的风光规模重新带入模块二，复核设备规模是否仍然合适。
9. 碳足迹模块把项目风光全年发电量（含弃电对应的发电量）全部计入风光生命周期排放，属于偏保守的简化分摊；未覆盖完整产品生命周期和所有认证规则。计算结果只能用于减排率预判，不等同于ISCC-EU正式认证。

## 五、独立脚本运行

独立运行时，可通过环境变量指定资源文件路径：

```bash
set FILE_WIND=风资源.xlsx
set FILE_SOLAR=光资源.xlsx
```

模块一：

```bash
python model1.py
```

模块二：

```bash
set TARGET_NH3_TON=50000
set MAX_GRID_RATE=0.10
set MAX_CURTAIL_RATE=0.20
python model2.py
```

模块三、四、五按顺序运行：

```bash
python model3.py
python economics.py
python model4_carbon.py
```

独立脚本的环境变量示例仅用于演示，正式测算请替换为项目真实参数。

## 六、版本修正说明

V1.1相对原始版本重点修正：

- 电解槽超额定功率补氢；
- 氢气库存更新和储罐容量边界；
- 储能SOC、充放电效率和充放电功率；
- 储能充电重复计入下网电率分母；
- 年度电量平衡与氢气物料平衡；
- 期初、期末库存差异；
- 年产氨目标约束；
- 模块二与模块四LCOA口径；
- 模块三和模块二共享同一套调度计算逻辑；
- 输入变化时清除Web端旧计算结果，避免引用过期方案。
